## Deliverable
A representative site without a bespoke business API can be navigated/read and produce evidence through a protected browser, with truthful login and effect boundaries.

## Implementation steps
1. Specify allowed browser operations, protected profile/session ownership and mediated team capabilities under the reviewed runtime contract. The bounded proposal prepares review only; BROW15-FZ01–FZ07 remain open and native #321 is not bypassed.
2. Implement navigate/read/download and necessary non-sensitive interaction with bounded output and exclusive input ownership.
3. Provide login/2FA/takeover handoff events and generation fencing without exposing passwords, cookies, raw CDP or unrestricted page-script authority.
4. Hold/refuse unsupported sensitive actions and demonstrate alternate browser/shell/script paths cannot release them.

## Acceptance criteria
- [ ] A controlled website task succeeds without a bespoke site API and returns actually observed evidence/files.
- [ ] Logged-in sessions do not make sending, payment or private upload generally available.
- [ ] Guest admin and tools cannot export/reuse raw sensitive browser credentials.
- [ ] Owner takeover fences agent input; return does not approve a pending action.
- [ ] Unsupported site/action behavior is actionable and explicit rather than false completion or a shell bypass.
