## Deliverable
Conversationally assigned responsibilities produce bounded subwork and retain CI/review waiting across restart, with evidence-based stall reporting.

## Implementation steps
1. Capture purpose/resources/budgets and trigger/schedule policy from authenticated owner assignment without repeated subtask setup.
2. Separate durable waiting responsibility from active execution/transport capacity and reservations.
3. Reconcile native sessions/effects before recovery; resume only trusted replay-safe operations with current authority.
4. Implement finite configured stall detection and a paused result containing approaches/evidence/recommendation; unrelated authorized work continues.

## Acceptance criteria
- [ ] Assigned-purpose events can create bounded subwork; outside-purpose findings remain proposals.
- [ ] CI/review waiting survives disconnect/restart without duplicate runs, busy execution or forgetting the obligation.
- [ ] Cancellation/stale transport retains capacity until settlement and blocks late publication.
- [ ] Repeated no-progress attempts pause before exhausting the budget; normal external waiting is not falsely labelled stalled.
- [ ] Unknown remote effects reconcile and cancelled/selected-only work is not resurrected; no replacement unselected issue starts.

## Tests and evidence
1. Fake-clock wait/restart/trigger-dedup fixtures -> one current responsibility and correct active usage.
2. Progress/no-progress sequences -> configured continuation or evidence-rich pause.
3. Crash/unknown effect/revoke/stop fixtures -> reconcile-only or fenced behavior, never blind retry.
