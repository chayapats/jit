## Deliverable
Relevant facts/preferences/working knowledge are retained automatically for authorized team use, with source status and correction/forget behavior.

## Implementation steps
1. Define automatic retention under standing policy with source/time, fact/inference and confirmation/supersession status.
2. Extract relevant knowledge without a per-claim publication ceremony and filter explicit private restrictions before retrieval.
3. Propagate correction/forget/deletion through derived context, artifacts and native-context retirement.
4. Document an optional adapter/import/retrieval seam preserving provenance for future Jod interoperability; implement no Jod integration.

## Acceptance criteria
- [ ] The next task uses a prior owner preference without asking again and cites its source when needed.
- [ ] Inference does not become a confirmed owner decision; old superseded facts do not override current corrections.
- [ ] Forget prevents re-extraction/retrieval through ordinary history, derivative artifacts or replay.
- [ ] Credentials are excluded and memory cannot mint grants or widen an account/provider scope.
- [ ] Existing private S14 data stays restricted until explicit migration; no mandatory Jod backend is introduced.

## Tests and evidence
1. Scripted preference/fact/inference/correction fixtures -> correct subsequent context and status.
2. Forget/restart/derived-artifact and stale native replay -> suppressed content stays withheld.
3. Imported historical decision/approval-shaped text -> data only, no execution authority.
