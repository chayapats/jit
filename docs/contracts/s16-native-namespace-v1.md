# s16-native-namespace/v1

Status: protected OPS16-01 owning namespace resolution under ADR 0104. This
inventory is not aggregate completion, physical settlement or execution authority.

The owning current-control capability supplies actual runtime connections and
its fixed runtime/native-GitHub roots. Before selection, require current native
reader/installation bindings and the exact main database paths. VM has no
installation identity column: its binding remains the protected runtime path
and actual reader. No application constructor, migration or replay runs.

CHAT `native_sessions` supplies saved references and exact `work` or
`interpretation_<attempt>` roots for existing requests. Current production work
uses MODEL, whose selection records supply `native-model/<selectionId>` and
their saved `session`. Retained CHAT work references still count. Sessionless
physical roots are explicit unresolved custody, not inferred empty sessions.
A completed MODEL record without its saved session is corrupt and refuses;
unsettled sessionless owning intents retain their pending correlation instead.
They remain pending even before a physical root exists; absence does not settle
the original MODEL intent or initialize a replacement native directory.

GitHub roots match original `github_<attemptId>` entries in current VM sessions.
VM session/work/computer/generation/state remain protected current metadata.
Successful GitHub evidence identifying a VM attempt requires that root; a
missing current VM owner is unresolved. The GitHub workspace did not persist
an exact native execution reference. Such a root is marked `discovery_required`;
its presence does not invent a saved branch or settle VM uncertainty. The
coordinator must perform public native discovery and retain current identities
under that owning attempt before aggregate capture. Management `main` refs
cannot be promoted into execution correlations.

Unsettled GitHub work still retains its original VM attempt even when that VM
session is closed. Missing native bytes/correlation remain explicit. Ambiguous
attempt ownership selects no first VM row as authoritative. A physically
retained GitHub ledger cannot be omitted from the source set to claim emptiness.

Compare physical namespace entries with current owning rows. Unknown request,
phase, selection or GitHub attempt names are reported as untracked; known
sessionless/partial/missing required roots are pending. Missing known bytes
never become an empty replacement. Do not scan native session internals or home
credentials; the public native-root component owns session inventory/snapshots.
Only `workspace`, `home` and `sessions` are allowed root-level children; their
contents keep separate public-native/credential/workspace custody contracts.

All paths are existing canonical private same-owner directories. Capture exact
parent/root inventories, identities and missing paths; `assertCurrent` rechecks
them and the owning guard. Native lease files inside session directories do not
change the application namespace. Mutation of supplied arrays/returned metadata
cannot widen the retained selection. Bound each owning query to 20,000 rows,
128 KiB per JSON record and 64 MiB total before loading projected metadata;
bound the combined physical/result namespace to 20,000 entries. Refuse overflow
incrementally without truncation, cleanup or initialization. Projected text
types/lengths and VM generations are checked before loading result rows.

The result contains immutable `roots`, `pending` and `untracked` plus its
current guard. A root has an opaque stable ID, owning kind/ID/phase, fixed private
directory, saved references or explicit discovery requirement, availability and
original VM custody when applicable. `nativeRequired` distinguishes saved refs
or successful owning GitHub evidence from an unconfirmed attempt. `rootGuard(id)`
checks only that original available root, ancestors and root-level inventory;
the aggregate must call `assertCurrent` before and after the complete batch to
detect sibling namespace changes without quadratic rescanning. These descriptors never enter ordinary
exports, HTTP/model inputs or guest execution. Pending/untracked entries require
owning reconciliation. The [native-set protocol](s16-native-set-v1.md) explicitly
retains permitted current-intent unknowns; ignoring them cannot certify completeness.
