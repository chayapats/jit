# app.external-evidence/v2

WEB14-01; consumes app.parallel-web/v1, app.memory-scope/v2 and app.context-provenance/v2. Canonical exported types: `ExternalEvidence`, `WebRead`, `ParallelResult` in `src/s14/parallel-types.ts`.

`ExternalEvidence` is one exact committed revision `{id,revision:1,generation:1}` with work/attempt/Bot, selected provider/mode/tool, requested URL when actually matched, actual returned URL, final URL only when reported, title/content, local retrieval timestamp, reported publication/retrieval/cache timestamps, freshness, truncation and `untrusted:true`. Search snippets are `snippet`; fetch excerpts are `excerpt`; `full_content_returned` requires a requested full read and a returned full_content string. It is a vendor-returned payload, not proof of complete or current coverage. Missing freshness is unknown. No local timestamp is represented as the vendor's fetch time. Credentials are redacted before persistence or model delivery.

`WebRead` preserves exact intended subject and a durable dispatched flag (true only when tools/call is handed to the transport), settings revision/mode, requested/finished times, remoteRequests, outcome, missing URLs, structured failures `{url,kind,status}`, omittedResults and reported SKU usage or null. No usage does not mean zero cost/consumption. Outcomes: running, success, partial, quota, schema_changed, service_error, blocked, private_context, credential_refused, cancelled, deadline, oversize, authority_changed, key_unavailable. A failed/missing source is not labelled read; stale reported cache stays labelled. Raw vendor error bodies/diagnostics never enter results. HTTP 429 is quota; HTTP 403/451 are blocked; 401 is key_unavailable. Unrecognized RPC/tool errors are service_error rather than guessed quota.

`ParallelWeb.inspect(actor,workId):{reads:WebRead[],evidence:ExternalEvidence[]}` is an offline owner query, bounded to 256 reads/1280 evidence revisions per work projection. `citation(tx,attemptId,evidenceId,revision):ExternalEvidence` requires committed evidence actually read by that attempt, exact revision and live memory lineage. Guessed, cross-attempt, stale or withdrawn references refuse. A returned fetch URL different from the requested URL cannot masquerade as the requested page; missing coverage stays visible.

Evidence publication is atomic with source registration and append-only source references on the captured work packet (maximum 64; further publication refuses oversize). The source conservatively inherits supplied source/claim/decision lineage; subsequent tools and final output recheck it. Correction/forget/delete retires dependent context, removes dependent evidence projections and redacts audit copies. Restored images consult the current independent lifecycle ledger before any worker/projection; interrupted read state never causes a query retry. Already disclosed vendor/provider copies are outside local lifecycle enforcement.

`Work.result` holds only the latest committed attempt ID; free-form bodies and their original ready/waiting states are stored separately in `work_results` and returned by `WorkView.results`, up to the granted 1 MiB. Effect resolution re-evaluates those stored states without changing citations or copying result bodies into receipts. Lifecycle withdrawal clears the pointer and result rows as well as dependent evidence/citations. This remains a foundation result, not a committed report/artifact contract. Typed report citation binding, report coverage/claim validation and immutable artifact downloads are TEAM14-01/report delivery work; no model citation string is silently certified here. The gateway returns exact committed evidence IDs for that later handler. Live retrieval quality, vendor DNS behavior and actual service/billing policy remain pending explicit opt-in evidence. Product UI: `src/s14/web-research.ts`.
