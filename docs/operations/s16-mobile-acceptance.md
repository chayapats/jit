# Native mobile acceptance — MOBILE16-01 / LIVE16-01

Use one immutable `s16-mobile-artifact/v1` ID and source commit per run. Keep installation-specific addresses, tokens, device IDs and raw logs in ignored `.local` receipts. Public proof includes hashes, exact test commands, outcomes and honest pending items. This checklist is not completed by source, compilation, provider HTTP acceptance or an unexecuted scenario.

## Packaged simulator / emulator lane (#426)

- Verify the complete artifact seal, native OS/architecture, source/client/native locks and original notices. Confirm Release JS runs without Metro, an Expo account, remote updates or installation-induced host enrollment.
- Connect through the existing protected service/password ingress. Check unavailable/expired credentials and SecureStore failure; no ordinary-file or shared-cookie fallback. Register two full origins/ports and prove sessions cannot cross them.
- Exercise English and Thai, light/dark, OS text scaling, accessible controls, safe areas, keyboard/composer, loading/empty/error/reconnect states. Check iOS and Android through their actual compiled renderer.
- Upload a real supported source file, read it through the owning FILE tool, send its exact receipt and produce a committed derived artifact. Check current preview and explicit owner-selected export bytes/hash. Picker cancellation, duplicate Send and response loss retain one original identity. An existing export name/symlink cannot be overwritten.
- Hold actual reads/commands with barriers. Background/foreground and service/session/target switches synchronously hide private projections; old layout acknowledgements and late responses cannot uncover or repopulate them. App-switcher/recents snapshots remain covered until the current public root lays out. A → B → A rejects the old picker/capture callback.
- Interrupt/restart after uncertain admission. Only the original receipt lookup runs automatically; no queued Send or reconstructed effect. Explicit retry, where still supported, reuses the immutable original command. Work continues on the protected service while the app is absent.
- Deliver generic controlled notification envelopes and default taps to known/unknown service hashes. Reauthenticate and read current chat/routine facts. Change/withdraw an approval before tap; the stale revision/hash cannot execute. One fresh in-app decision executes the exact effect once. HTML, OS action buttons and notice data cannot invoke that decision path.
- Check unconfigured/denied/provisional/restored notification states, protected subscription intent, unknown response/restart hash lookup, original-token disable and token rotation. No automatic subscribe, SDK auto-init or analytics route; provider acceptance is labelled separately from OS delivery.
- Check unavailable/denied microphone, one finite native capture, explicit Stop/Cancel and editable transcript. Native background/interrupt/limit consumes the lease without automatic resume; no audio file or automatic Send/Decide. Lost transcription retains only its original read-only identity. Silence/scripted PCM fixtures do not establish physical quality.
- Run frozen root/client installations, root/native typechecks, affected deterministic/composed suites, opt-in Darwin exclusive-export fixture and existing browser regressions. Record exact tested head, counts, commands and actual artifact hashes.

## Exact physical device / account lane (#431)

Record an exact physical device/OS/architecture and the protected signing/build identity privately. Do not substitute simulator results.

- The owner separately authorizes any developer-account setup, credential/policy change, login/2FA, billing, store publication or real-device installation/data changes that require it. No credential is pasted into a prompt, repo, app bundle or working VM. No payment/account action is necessary for deterministic implementation proof.
- Confirm SecureStore/keychain/keystore custody under the real signing identity, OS lock, backup/restore, reinstall/update and shared-device/session changes. Do not clear real data without its exact approval. Confirm authenticated service binding and normal TLS on device.
- Match the public application ID, Android public client configuration, protected APNs topic/environment and FCM project. Keep APNs/FCM private signing files only on the protected service. Confirm manifest-level auto-init/analytics/advertising controls in the actual shipped APK.
- Opt in visibly; verify real APNs/FCM registration and generic physical delivery/tap in foreground, background and terminated states. Denied/provisional permission, token rotation, device revoke, owner reset, offline/restart and OS background restrictions must stay truthful. Record latency/duplicates and receipt IDs without publishing raw device tokens or private content.
- Capture actual microphone audio and check measured finite duration/PCM, interruptions, route changes, cancellation, local-only transcription and Thai accuracy. Do not use private recordings or benchmark data for training. This is acceptance, not OLIV/Whispy training or a billable GPU run.
- Verify signed update and compatible rollback under real OS downgrade rules, fresh reauthentication and retention of protected service facts. No silent uninstall, cache resurrection, data conversion or owner-host cutover.
