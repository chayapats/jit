# Bounded S14 team graphs

Owner-confirmed defaults are 2 concurrent Bots, 30 minutes and 40 reads per work item (#251 comments). The grant records concurrency and reads separately from finite model/tool calls. Non-secret finite process configuration supplies global/credential-route/Bot/computer ceilings; it does not silently reduce or widen an immutable grant.

Use the two trusted research/synthesis handlers and a finite validated DAG. Default selected-Bot analyses are independent; synthesis waits for committed settled dependencies and retains explicit sibling gaps. Every assignment owns independent native sessions and tools. Receiver access is checked before committed handoff text enters context, preserving original lineage/access revisions. Sources and model proposals never mint authority.

The public Schway shared process lifecycle prerequisite has landed and its exact packed-consumer conformance passes. Use one opaque owner per process in every S14 host's auth.lifecycle. Keep legacy concurrency untouched. A durable active transport reservation outlives cancellation until actual return and cleanup. Interrupted native work remains blocked/reconciliation-required; this slice does not invent automatic replay (#254).

Work lanes expose observed timestamps and safe queue/dependency/stop reasons to the existing Opus design. Owner lane cancellation and future-default settings use exact typed commands/receipts; no UI control supplies authority by appearance. See app.work-graph/v1 and the HTTP handoff for exact signatures and schema.

## PR #273 logic-gap refinement

Committed ingress wakes the process's existing drain rather than waiting for a pending run to settle. Drain ownership is installed before executor entry so concurrent/reentrant calls cannot create another drain; all admission/transport ceilings remain unchanged. Lane records now retain observed queued/dependency-wait start times and expose the current held capacity ceiling. Lane-stop receipts include the service-resolved originating conversation, preserving the work pane after receipt replay.

## First-run integration with main

Combined schema 10 retains the first-run computer activity table alongside every graph, report and review table; unreleased schemas 1–9 refuse with fresh-state. Provider-derived default routes use the same process-owned credential lifecycle as explicit routes in chat, research and computer hosts. Shutdown awaits admitted transports and device sign-in cleanup before disposing that owner or closing the store.

Explicit `work.retry` and `work.summarize` remain single first-Bot recovery attempts under the original live grant and spent reservations. The shared drain admits them through the same capacity/transport barriers as graph lanes. Recovery refuses any unsettled transport even after provisional result commit, cancels only unstarted original lanes, and retains their history plus all committed evidence. It never restarts the original graph, refunds usage or revives stopped authority. Evidence-only synthesis keeps zero tools and exact current source pins.
