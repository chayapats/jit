# Isolated coding evidence and exact Git effects

The confirmed product/authority baseline remains S14. Engineering choices for CODE14-01 are a typed repository resource pinned to one Bot/origin/base commit, preloaded files inside its existing network-free computer, an independent clone and branch per work, public Schway core tools through the guarded backend, and service-captured immutable diff/check artifacts. There is no host checkout/execution fallback, automatic clone credential, Project scope or broadened egress. The existing `computer` tool explicitly grants that Bot's workspace; a repository grant additionally authorizes the named repository identity. No other Bot's computer/session follows.

The exact coding start captures offline or registry-required argv checks. The current runtime cannot enforce a registry path, so registry-required commands remain skipped with an actionable unavailable reason. An owner cannot enable a broader path merely by choosing it in a command. Later egress support requires a separate explicit owner scope and enforcement proof. Preloading and real image/package availability remain operator/real-Linux evidence gates.

After actual edits the trusted handler creates a local immutable commit with hooks/helpers/config/signing disabled and checks whether head or files changed during actual tests. Failed/skipped/unknown checks, no tests or changed content stay partial. Test log excerpts are bounded and labelled. Diff/check artifacts inherit existing report/source lineage and download safeguards. Reviewable means actual evidence exists, not owner completion. Work waits for review, preserving the live exact-effect proposal seam when the owner explicitly selected effect_push; that tool never authorizes dispatch without one exact approval. Coding shell work is never replayed automatically.

Schema 13 introduces repository grants, captured coding jobs, per-attempt run status and pre-dispatch actual check observations; no credential column exists. Earlier unreleased formats refuse before writable open. Duplicate plan/check caches are removed by existing lifecycle deletion. Existing report/artifact immutability and independent withdrawal/reservation ledgers remain authoritative.

Deterministic fake-runtime/generated-repository fixtures prove the protocol and actual local test commands. They do not prove kernel isolation, real Linux resource bounds, live GitHub or product UI acceptance.
